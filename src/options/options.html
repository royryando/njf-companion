Privacy

  • Everything stays in this browser. NJF Companion has no server, no analytics and no tracking.
  • Passwords are encrypted with AES-GCM using a key that cannot be exported and never leaves this device.
  • Network requests go only to the NJF environments you add, and only to their sign-in, token refresh, sign-out, menu and service health endpoints.
  • The extension runs only on environments you grant access to. You can revoke access at any time.
